# 433 MHz RF

> Source: https://apps.developer.homey.app/wireless/433

## Overview

433 MHz is a radio frequency used by many low-cost wireless devices like switches, sensors, and remotes.

## Requirements

- Homey Pro (not available on Homey Cloud)
- Permission: `homey:wireless:433`
- Optional package: `homey-rfdriver`

```json
{
  "permissions": ["homey:wireless:433"]
}
```

**RF Driver Library:** [github.com/athombv/node-homey-rfdriver](https://github.com/athombv/node-homey-rfdriver/)

## Signal Definition

Define signals in your driver manifest:

```json
{
  "id": "my-rf-device",
  "class": "socket",
  "capabilities": ["onoff"],
  "rf433": {
    "signal": {
      "id": "my-signal",
      "sof": [250],
      "eof": [250],
      "words": [
        [250, 750],
        [750, 250]
      ],
      "interval": 10000,
      "repetitions": 10,
      "sensitivity": 0.7,
      "minimalLength": 24,
      "maximalLength": 24
    }
  }
}
```

## Signal Parameters

| Parameter | Description |
|-----------|-------------|
| `sof` | Start of frame (microseconds) |
| `eof` | End of frame (microseconds) |
| `words` | Bit definitions [high, low] |
| `interval` | Time between repetitions |
| `repetitions` | Number of signal repeats |
| `sensitivity` | Signal matching tolerance |
| `minimalLength` | Minimum bit count |
| `maximalLength` | Maximum bit count |

## Transmitting Signals

```javascript
'use strict';

const Homey = require('homey');

class MyDevice extends Homey.Device {
  
  async onInit() {
    this.registerCapabilityListener('onoff', this.onCapabilityOnoff.bind(this));
  }
  
  async onCapabilityOnoff(value) {
    const signal = this.homey.rf.getSignal433('my-signal');
    
    // Create the bit string
    const address = this.getData().address;
    const command = value ? '1' : '0';
    const payload = address + command;
    
    // Transmit
    await signal.tx(payload);
  }
}

module.exports = MyDevice;
```

## Receiving Signals

```javascript
class MyDriver extends Homey.Driver {
  
  async onInit() {
    const signal = this.homey.rf.getSignal433('my-signal');
    
    signal.on('payload', (payload, first) => {
      if (first) {
        this.log('Received RF signal:', payload);
        this.handleSignal(payload);
      }
    });
    
    await signal.enableRX();
  }
}
```

## Pairing with Signal Learning

```javascript
async onPair(session) {
  const signal = this.homey.rf.getSignal433('my-signal');
  
  session.setHandler('learn', async () => {
    // Enable learning mode
    await signal.enableRX();
    
    return new Promise((resolve, reject) => {
      const timeout = setTimeout(() => {
        signal.disableRX();
        reject(new Error('Timeout'));
      }, 30000);
      
      signal.once('payload', (payload) => {
        clearTimeout(timeout);
        signal.disableRX();
        resolve({
          name: 'Learned Device',
          data: { address: payload }
        });
      });
    });
  });
}
```

## Signal Encoding

Common encoding schemes:

### Manchester Encoding
```json
{
  "words": [
    [500, 1000],
    [1000, 500]
  ]
}
```

### PWM Encoding
```json
{
  "words": [
    [350, 1050],
    [1050, 350]
  ]
}
```

## Best Practices

1. **Capture real signals** - Use an SDR to analyze actual device signals
2. **Adjust sensitivity** - Find the right balance for your devices
3. **Handle duplicates** - Use the `first` parameter to ignore repeats
4. **Test range** - 433 MHz range varies significantly
5. **Document protocols** - RF protocols are often undocumented
