# App Store Guidelines

> Source: https://apps.developer.homey.app/app-store/guidelines

## Overview

These guidelines ensure quality and consistency across all Homey apps.

## Naming Guidelines

### App Name
- Clear and descriptive
- Include brand name if applicable
- No excessive capitalization
- No emojis in name

### Examples
- ✅ "Philips Hue"
- ✅ "Weather Forecast"
- ❌ "THE BEST LIGHT APP!!!"
- ❌ "🔥 Super Lights 🔥"

## Description Guidelines

### Required Content
- Clear explanation of functionality
- List of supported devices (if applicable)
- Any prerequisites or requirements

### Writing Style
- Professional and concise
- No marketing hyperbole
- Accurate feature descriptions
- Include setup instructions if needed

## Image Guidelines

### Quality Requirements
- High resolution
- Clear and professional
- Represent actual functionality
- No misleading screenshots

### Sizes
| Image | Dimensions | Format |
|-------|------------|--------|
| Small | 250x175px | PNG |
| Large | 500x350px | PNG |
| XLarge | 1000x700px | PNG |

## Icon Guidelines

### Driver Icons
- Format: SVG
- Single color (no fills, just paths)
- Clear and recognizable
- Consistent with Homey's design language

## Category Selection

Choose appropriate categories:

| Category | Use For |
|----------|---------|
| `appliances` | Kitchen, laundry, home appliances |
| `climate` | Heating, cooling, ventilation |
| `energy` | Power monitoring, solar, batteries |
| `lights` | Lighting and LED control |
| `music` | Audio and music streaming |
| `security` | Alarms, cameras, locks |
| `tools` | Utilities, automation tools |
| `video` | TVs, projectors, streaming |

## Functionality Requirements

### Must Have
- Work as described
- Handle errors gracefully
- Proper logging (no spam)
- Responsive UI (if applicable)

### Must Not
- Contain malware or unwanted behavior
- Access data without permission
- Spam users with notifications
- Crash or hang frequently

## Privacy Requirements

- Only collect necessary data
- Explain data usage in description
- Secure sensitive data
- Respect user privacy preferences

## Update Requirements

- Fix reported bugs promptly
- Maintain compatibility with Homey updates
- Respond to user feedback
- Keep dependencies updated

## Rejection Reasons

Common reasons apps are rejected:

1. **Incomplete functionality** - Features don't work
2. **Poor quality** - Crashes, errors, bad UX
3. **Misleading description** - Doesn't match functionality
4. **Policy violations** - Security or privacy issues
5. **Inadequate support** - No valid contact info

## Appeal Process

If your app is rejected:

1. Read the feedback carefully
2. Make required changes
3. Resubmit with explanation
4. Contact developer support if needed
