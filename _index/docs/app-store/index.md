# App Store

> Source: https://apps.developer.homey.app/app-store/

## Overview

The Homey App Store is where users discover and install apps. Publishing your app makes it available to all Homey users.

## Topics

- [Publishing](./publishing.md) - How to publish your app
- [Guidelines](./guidelines.md) - App Store requirements
- [Verified Developer](./verified-developer.md) - Become a verified developer
- [Updating](./updating.md) - How to update published apps

## Quick Start

1. **Develop** - Create and test your app locally
2. **Validate** - Run `homey app validate`
3. **Publish** - Run `homey app publish`
4. **Review** - Wait for App Store review
5. **Live** - App becomes available to users
